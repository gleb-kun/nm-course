# nm-course

Материалы для курса по численным методам.

Репозиторий содержит лекционные материалы, практические задания, примеры и справочную литературу. Для численных вычислений используются Python и блокноты Jupyter, а для оформления практических заданий — LaTeX.

Часть материалов представлена на английском и русском языках. См. файлы README:
- [Русский](README_RU.md),
- [Английский](README.md).

## Назначение

- `lectures/` — лекционные материалы и примеры в блокнотах Jupyter.
- `practices/` — практические задания в блокнотах Jupyter и LaTeX, а также вспомогательные файлы с данными.
- `literature/` — справочная и дополнительная литература в форматах PDF и DjVu.
