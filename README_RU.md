# nm-course

Материалы для курсов, которые посвящены вычислительной математике.

Репозиторий содержит лекционные материалы, практические задания, примеры и справочную литературу.

Часть материалов представлена на английском и русском языках. См. файлы README:
- [Русский](README_RU.md),
- [Английский](README.md).

## Назначение

- `lectures/` — лекционные материалы.
- `practices/` — практические задания, а также вспомогательные файлы с данными.
- `literature/` — справочная и дополнительная литература.
